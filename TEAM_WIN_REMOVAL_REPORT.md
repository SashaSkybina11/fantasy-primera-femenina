# Удаление бонуса за победу из рыночных цен

## Результат

- Победа команды влияет на изменение рыночной цены: **НЕТ**.
- Победа команды влияет на Fantasy-очки: **ДА, прежние +2**, без изменений.
- Старт + гол = **+130 €**; старт + 2 гола + жёлтая = **+215 €** при WIN, DRAW и LOSS.
- Вратарская формула сохранена, включая 5 пропущенных → −40 €, 6 → −50 €.

Результат матча больше не является входным параметром расчёта цены. Preview не возвращает настройки бонуса. Версия формулы включена в revision, чтобы старый preview нельзя было применить после обновления.

- `frontend/src/pages/AdminPlayerPricesPage.tsx`: удалены поле бонуса, загрузка/сохранение настройки и строка победы в детализации цены.
- `frontend/src/services/api.ts`: удалены методы настройки и связанные поля PricePreview.
- `frontend/src/contexts/LocaleContext.tsx`: удалены переводы настройки бонуса на трёх языках.
- `frontend/src/styles.css`: удалены неиспользуемые селекторы блока настроек.

## Старые туры и безопасность базы

При пересчёте выбранного тура старая надбавка заменяется расчётом только по разрешённым событиям; teamResultPriceDelta записывается как 0, teamWinBonus как null. Для последующих записей, пересчитываемых вместе с ним, из priceDelta вычитается сохранённый teamResultPriceDelta, обновляются начальные/конечные цены и очищаются поля бонуса. Повторное применение не вычитает бонус снова и не создаёт дублей.

Более ранние, не затронутые пересчётом туры сохраняют историю и входят в начальную цену выбранного тура. Чтобы убрать все ранее начисленные бонусы сезона, нужен пересчёт начиная с самого раннего тура, содержащего бонус. Массовый пересчёт рабочей базы автоматически не запускался. Новые начисления бонуса невозможны независимо от содержимого старой настройки.

Рабочая база не изменялась. Интеграционные проверки выполнялись в отдельной локальной тестовой базе.
